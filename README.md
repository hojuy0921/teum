# TEUM

필요한 사람과 할 수 있는 사람을 연결하는 지역 기반 마켓·레슨·서비스 커뮤니티.

## 실제 서비스 배포

아래 버튼을 눌러 Render에서 이 저장소를 바로 배포할 수 있습니다.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/hojuy0921/teum)

배포 구성은 render.yaml에 포함되어 있습니다.

실서비스 데이터와 업로드 파일은 영구 저장이 필요하므로, Render에서 유료 Web Service와 Persistent Disk를 사용하도록 구성되어 있습니다.
